## Publish with GitHub Pages

1. Extract the ZIP into a folder. Keep all files and folders together.
2. Create a new public GitHub repository called `uae-ai-powered-vr`.
3. Upload the **contents** of the extracted folder (not the ZIP). Ensure `index.html` is at the repository root. With hundreds of narration files, GitHub Desktop is recommended rather than uploading everything in one browser batch.
4. In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
5. Wait for the deployment to finish and use the published URL shown in Pages. It will generally look like `https://YOUR-GITHUB-USERNAME.github.io/uae-ai-powered-vr/`.
6. Open the live site and select **Download QR** to get a QR code that points to your own GitHub Pages URL.

All audio, graphics, fonts, JavaScript libraries and certificates are included. No API key or server is required. Use HTTPS for compatible WebXR headsets. No learner login is needed.

For Windows, GitHub Desktop can publish the entire folder in one commit. Install GitHub Desktop, sign in, clone your new repository, copy all extracted files into the cloned repository, commit, then push origin. If you use the web uploader instead, upload root files and each folder in manageable batches, preserving paths.

**Local test:** run a static HTTP server from the extracted directory (for example `python -m http.server 8000`) and open `http://localhost:8000/`. Double-clicking index.html may not work because browsers restrict local JavaScript modules.

The QR code is generated from the current website address when hosted. The illustrated fallback and teacher guide are also included. Existing school logo, certificate and audio assets are intended for the requested school educational project.
